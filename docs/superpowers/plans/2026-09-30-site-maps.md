# Site Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- Every sidewalk site gets a zone map: orange sidewalk, red heated, blue do-not-touch, plus a priority flag.
- Matt draws it on Anchorage aerial imagery, with the old route-sheet page beside it as a tracing guide.
- Crew and leads see it on their phones.
- The 11 routes and about 54 sites come in from the PDFs, with no typing.

**Architecture:**
- **`geo.js` from Bootprint.** The pure geometry (`project`, `calcAreaSqm`, `calcPerimeterM`, `isSelfIntersecting` and their helpers) moves into a UMD `geo.js`, used **byte-identical** by the phone app and the Apps Script backend. The server computes `area_sqft`.
- **New `Zones` record tab**, the same shape and the same revision, conflict and lock rules as the Foundation's tabs.
- **Maps use vendored MapLibre GL** (Bootprint's copy). MOA 2024 tiles are primary, with Esri as the fallback.

**Tech Stack:** as Foundation, plus MapLibre GL (vendored) and Python + pymupdf for the PDF extraction tooling (already on the laptop).

**Spec:** `docs/superpowers/specs/2026-09-30-site-maps-design.md`

## Global Constraints

- Zone `type` is an **allow-list**: `sidewalk`, `heated`, `no_touch`. The backend refuses anything else.
- `area_sqft` is **computed by the server** from `ring`. A client-sent value is ignored.
- A ring needs ≥ 3 corners and must not cross itself (Bootprint's `isSelfIntersecting`, with drawn corners at accuracy 0, i.e. a 1.5 m threshold).
- **The reference picture is never sent anywhere.** It lives in an object URL on the editing device only.
- `seedRoutes` is idempotent by name (case and whitespace insensitive). Matt reviews the extracted list **before** it ships.
- Only admin writes zones; every read needs sign-in. All Foundation constraints still hold:
  - who comes from the token;
  - the body decides success;
  - `titan-snow-*` keys;
  - the service worker never caches Apps Script or touches other apps' caches;
  - judgment values ship blank.
- `phone geo.js === backend geo.js` byte for byte (test-enforced).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Treated offered on a heated zone, or anything offered on a no_touch zone.** This sub-project has only the read view, but the legend and the zone sheet must already say "check only" / "do not touch".
2. **A crew member sees an empty map and thinks the site has no walks.** Pinned by the "Map not drawn yet" test.
3. **Imagery outage hides the zones.** Pinned by the imagery-failure test (tiles routed to 404).
4. **A duplicate route or site from running seed twice, or a name that differs only in case or dashes.** Pinned by the idempotency test.
5. **A reference picture leaking to the backend or into storage.** Pinned by asserting on every request body and on `localStorage`.
